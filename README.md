# Cursor DevTools Static Landing Page - [Live Demo](https://anoop-rajoriya.github.io/cursor-devtools-landing-page-css/)

A landing page UI of the [cursor coding tool](https://cursor.com/). It implemented using vanilla HTML and CSS.

## What i Built

- I capture high quality screenshot of the assets and extract them using graphic editing tool (Gimp). At starting i'd stuck because i was not able to found assets used in real website.
- I setup design system by defining colors, fonts sizes and weights as CSS varialbes.
- I implemented the core sections of the landing page, includes header, hero, features, testimonials, social proof, CTA and footer.
- I made it responsive for three devices - mobile, tablet, and desktop viewport by following mobile first approache.
- I define some reusable styles rules so CSS not repeated for the redundent compnents.

## What can you Build

As a beginner you can try to build a desktop view of the landing page. If its feels easy then you can try to re-create the responsive version that adapt to mobile, tablet and desktop viewports.

### Challenge Checklist

- Prepare a project directory contains all the necessary fiels and dirs:
  - `index.html`
  - `style.css`
  - `.gitignore`
  - `/assets`
  - `README.md`
- Collects all necessary assets colors, fonts, images, icons etc. You can also use repos assets.
- Implements the following necessary sections of the landing page:
  - Header
  - Hero
  - Features Sections
  - Social Proof
  - Testimonials
  - Changelog
  - CTA
  - Footer
- You can add some sections or modify displayed information by you'r self.
- Use Flex and Grid layout system for differente usecases like cards containers or layouts.

## Learning Outcomes

- It makes you undestand how to tackle the real world UI designes and use different concepts of the CSS.
- How to embed images, videos, icons within the HTML and styles them for different scenerios.
- How to build different complex layouts using flex or grid.

## How to Run

- Download and clone the repository.
- open the `index.html` file within any web browser.
